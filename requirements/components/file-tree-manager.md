# file-tree-manager

文件树管理器

展示当前 workspace 下 requirements/ 内的文件树，并支持在树上管理文件与文件夹。

所有文件操作调用 <file-writer /> 里声明的接口。

## 节点

2 种节点
- 文件夹
- 文件

- 数据源为当前 workspace 的 requirements/ 目录，跳过隐藏文件与 node_modules/.git 等无关目录
- 排序：文件夹在前、文件在后，各自按名称排序
- 点击文件夹名：展开 / 收起，默认展开
- 点击文件：选中并高亮，选中态与 url 锚点由所在页面处理（见 pages/home/left.md）

## 文件夹操作

- 点点点 icon
  - hover 后显示
  - 点击弹出菜单
    - 新建文件
      - 弹窗输入文件名，确认后调用 <file-writer /> 的新建文件接口
      - 成功后刷新文件树，并自动选中新文件
    - 新建文件夹
      - 弹窗输入文件夹名，确认后调用 <file-writer /> 的新建文件夹接口
      - 成功后刷新文件树
    - 重命名
      - 弹窗输入新名称（默认填入当前名称），确认后调用 <file-writer /> 的重命名接口
      - 成功后刷新文件树
    - 删除
      - 二次确认，提示「文件夹内的文件将一并删除」
      - 确认后调用 <file-writer /> 的删除接口
      - 成功后刷新文件树

## 文件操作

- 点点点 icon
  - hover 后显示
  - 点击弹出菜单
    - 重命名
      - 同文件夹的重命名
    - 删除
      - 二次确认
      - 确认后调用 <file-writer /> 的删除接口
      - 成功后刷新文件树

## 根目录

- 文件树顶部标题栏（requirements/）提供「新建文件 / 新建文件夹」入口，作用于根目录

## 交互细节

- 菜单关闭时机：点击菜单项、点击菜单外区域、按 Esc、再次点击点点 icon
- 名称输入校验：非空、不以 `.` 开头；文件名不含 `/`；文件夹名可用 `/` 一次创建多级
- 操作失败时，以提示条展示接口返回的错误信息
- 新建 / 重命名后，所属文件夹若未展开则自动展开
- 操作对象为当前选中文件时，成功后同步更新选中与 url：
  - 重命名 → 更新为新路径
  - 删除 → 清除选中
- 空树或空文件夹：展示「暂无文件」占位
