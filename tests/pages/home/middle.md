# Home Middle（中间内容区）

进入页面且未选中文件时

- 中间内容区展示空状态（无文件内容）

选中文件时

- 加载并展示当前选中文件的 markdown 内容
- 顶部不展示文件名
- 文档的第一个 `#` 作为标题渲染
- 标题后的内容作为正文编辑
- markdown 之间有空行的，渲染时保留适当间隔

编辑文件内容时

- 可以正常编辑正文内容
- meta 信息（frontmatter）不展示在编辑器中，但保存时保留

点击保存按钮时

- 标题和正文合并为一个 markdown 文档
- 调用 <file-writer /> 的写接口，保存到原文件路径
- 保存成功后有成功反馈

按下 cmd + s 时

- 触发保存，效果同点击保存按钮
