# Home Right（右侧依赖区）

获取提示词

- 选中文件后，右侧展示「获取」按钮
- 点击「获取」按钮时
  - 调用 <view-and-diff /> 的接口，入参为当前文件路径
  - 弹出弹框，展示接口返回的内容
  - 弹框内容顺序：文件内容、inject 依赖内容（<inject content="路径"> 包裹）、涉及文件的修改 diff（<diff content="路径"> 包裹）
  - 点击关闭按钮或遮罩可关闭弹框

依赖列表

- 如果文件不是 markdown 文件，不展示依赖列表
- 如果是 markdown 文件但 meta 未声明 inject，不展示依赖列表
- 如果 markdown 文件 meta 声明了 inject: ["依赖"]，展示文件依赖列表

展示依赖列表时

- 仅显示依赖名称和文件路径
- 依赖路径相对于 requirements 目录解析

点击依赖项时

- 跳转到对应的依赖文件
- 文件树中高亮跳转后的文件
- url 同步更新为跳转后的文件路径

新增依赖

- 仅当选中的文件为 markdown 文件时，右侧面板底部展示「新增」按钮
- 点击「新增」按钮时，弹出文件树选择器弹窗
  - 展示 requirements/ 下的所有文件（排除当前文件自身）
  - 支持前端搜索（按文件名或路径过滤）
  - 支持多选（checkbox）
  - 已在 inject 中声明的依赖展示为「已添加」，不可再选
  - 点击确定后，将所选文件加入到当前 markdown 的 meta inject 依赖中（保留已有依赖）
  - 点击取消（或遮罩 / Esc）关闭弹窗，不修改文件
- 新增成功后依赖列表刷新，展示新增的依赖
